- [ ] Make a new html markup that is similar to the explicit cutter specification `<c:D>`, but for specifying that the cutter *should not change as a result of any other html markup applied to the text segment. We'll call this "original cutter" and use `<oc>` for the start and `</oc>` for the end of the text segment. For example `<oc><scale:2.0>larger text without larger cutter</scale></oc>` would scale up the text without affecting the cutter size. Now, significantly, `<oc>` only prevents cutter changes *due to other html markup that applies to the text segment; the cutter can still change e.g. due to horizontal text compression on long lines, or due to global horizontal text scaling due to compression applied to some other line. The motivation for `<oc>` is to be able to easily make sure that marked-up text doesn't end up with a different cutter from the non-marked-up text around it.
