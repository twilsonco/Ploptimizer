  - **The curve family is forced by the two constraints.** A circular fillet is G1 (κ jumps 0 → 1/r at each tangent point — the reported artifact), and a curvature-continuous fillet can *never* tile into a circle at 100% (a circle has κ ≠ 0 everywhere), so no fillet family satisfies both requirements.
