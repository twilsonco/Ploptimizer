  - **The curve family is forced by the two constraints.** A circular fillet is G1 (κ jumps 0 → 1/r at each tangent point — the reported artifact), and a curvature-continuous fillet can *never* tile into a circle at 100% (a circle has κ ≠ 0 everywhere), so no fillet family satisfies both requirements. The superellipse quadrant resolves it: for **n > 2 its curvature at its axis vertices is exactly zero** (near a vertex `x = rx − c·y^n`, so `κ ∝ y^(n−2) → 0`) and its tangent there is exactly axis-aligned, so the straight edges (κ = 0) join the patches with no curvature jump. The exponent `n = 2/f` pins the family's endpoints: `f → 0` ⇒ `n → ∞` (sharp rectangle), `0.5` ⇒ `n = 4` (squircle), `1.0` ⇒ `n = 2` (the **exact** ellipse/circle).
